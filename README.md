# React Nav Swapper 🔄

[![GitHub License](https://img.shields.io/badge/license-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Compatible with React.dev](https://img.shields.io/badge/compatibility-react.dev-green)](https://react.dev)

A non-intrusive JavaScript utility that safely swaps "Reference" and "Community" menu items on React.dev's navigation bar while maintaining all original functionality.

## Features ✨

- Session-persistent swap (once per browser session)
- Zero dependencies
- Preserves original website functionality
- Graceful error handling
- Cross-browser compatibility
- Dark/Light mode support
